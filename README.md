# Zahra Batool — AI & Digital Solutions Portfolio

A responsive React portfolio built with Vite, Framer Motion and Lucide icons.

## Requirements
- Node.js 18 or newer
- npm (included with Node.js)

## Run locally
1. Extract this project folder.
2. Open the folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed in the terminal (usually http://localhost:5173).

## Create a production build
Run `npm run build`. Vite creates the deployable website in the `dist` folder.

## Notes
- No personal photo or childish stock illustrations are used. The hero visual is built with CSS and animated interface elements.
- AI automation and chatbot services are described transparently as emerging / prototype-stage offerings. Update the wording as your skills and project experience grow.
- Contact and social links are configured in `src/main.jsx`.
