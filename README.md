# Zahra Batool | AI Engineer Portfolio

AI Engineer | AI Enthusiast | AI Solutions Developer. Static site (HTML, CSS, JavaScript), no build step. Open `index.html` to preview.

- Add real projects: edit the `PROJECTS` list near the top of the script in `index.html` (categories: AI Solutions, Websites, Social Media). Each entry supports an image, live link and GitHub link.
- Concept cards in "Solutions & Capabilities" are labeled as concepts. Set `showConcepts:false` in `CONFIG` to hide them once you have real work.
- Contact form: set `formEndpoint` in `CONFIG` (for example a Formspree URL) to send without an email app. Otherwise it opens the visitor's email app.
